# Local npm publication

The npm package is generated by Kotlin/JS. Maven `1.0.0-SNAPSHOT` becomes
npm `1.0.0-next.0`; use `-PnpmVersion=VERSION` to override it. Stable Maven
versions produce the same stable npm version. Prereleases use the `next` tag.

From this repository, build and test on Windows:

```powershell
.\gradlew.bat --no-daemon jsNodeTest jsBrowserTest jsProductionExecutableCompileSync nodeIntegrationTest
npm pack ./build/js/packages/json-schema-ref-parser-kmp --ignore-scripts --pack-destination ./build
npm publish ./build/zenwave360-json-schema-ref-parser-kmp-1.0.0-next.0.tgz --access public --tag next
```

On Linux/macOS use `./gradlew` with the same arguments. The generated package
includes the runtime modules, TypeScript declarations, README, and LICENSE.
Publish the tarball, rather than the repository root or `nodejs-test-project`.
Each published version must be unique; select another npm version before
rebuilding if the default version is already published.
